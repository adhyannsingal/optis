# PHAROS

PHAROS is a HackUMass XIV assistive prototype for seated object guidance and tabletop retrieval. A camera feed supports spoken directions. A fixed camera verifies the pickup zone before a stand-mounted Waveshare arm moves a lightweight bottle to a tray. The body mount is demonstrated with actuator power disconnected.
